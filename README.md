# OBD Monitor — приложение для ELM327 BLE

Android-приложение (Java), которое подключается по Bluetooth Low Energy
к адаптеру вроде того, что на фото (ELM327 ver 1.5, BLE 4.0, клон типа
"Emitron"), опрашивает обороты, скорость, температуру ОЖ, нагрузку
двигателя, положение дросселя и уровень топлива, и рисует это в виде
приборной панели с круговыми шкалами и прогресс-барами.

## Как открыть проект
1. Открой папку `ObdMonitor` в Android Studio (File → Open).
2. Дай Gradle синхронизироваться — он подтянет плагины и зависимости
   сам, отдельно ничего ставить не нужно.
3. Собери и запусти на телефоне (минимум Android 8.0 / API 26).

## Важный нюанс про сам адаптер (обязательно прочитай)

Дешёвые "ELM327 BLE" адаптеры (в том числе судя по фото — Emitron)
почти никогда не реализуют официальный OBD-профиль BLE. Вместо этого
внутри стоит модуль вроде HM-10/HM-19, который просто превращает
BLE-соединение в прозрачный "провод": ты пишешь туда обычные ELM327
AT/OBD-команды текстом (`ATZ`, `ATSP0`, `010C` и т.д.), а он присылает
ответ тем же текстом — точно так же, как через классический Bluetooth
SPP или по USB.

У таких модулей сервис и характеристики почти всегда один из двух
вариантов:
- `FFE0` (сервис) / `FFE1` (запись+уведомления) — самый частый вариант (HM-10)
- `FFF0` (сервис) / `FFF2` (запись) + `FFF1` (уведомления)

`BleObdManager.java` сначала ищет именно эти UUID, а если не находит —
включает запасной вариант: перебирает вообще все характеристики устройства
и берёт первую с флагом "запись" и первую с флагом "уведомления". Это
должно сработать почти для любого клона, но не даёт стопроцентной
гарантии для совсем экзотических прошивок.

**Если после подключения в журнале не появляется "GATT подключен..."
или данные не идут:**
1. Поставь приложение **nRF Connect** (Nordic, есть в Google Play) —
   подключись им к адаптеру и посмотри реальный список сервисов/характеристик.
2. Впиши найденные UUID в начало `BleObdManager.java`, в массивы
   `KNOWN_WRITE` и `KNOWN_NOTIFY` — приложение сразу заработает.

## Что показывает приборная панель
- Обороты двигателя (PID `010C`) — круговая шкала, зеленеет/желтеет/краснеет ближе к максимуму
- Скорость (PID `010D`) — круговая шкала
- Температура охлаждающей жидкости (PID `0105`)
- Нагрузка двигателя (PID `0104`)
- Положение дросселя (PID `0111`)
- Уровень топлива (PID `012F`)
- Журнал внизу — сырые команды/ответы, полезно для отладки

Опрос идёт по кругу с интервалом ~300 мс между командами — это разумный
компромисс между частотой обновления и тем, что сам ELM327-чип не
успевает захлебнуться.
